# 生活模式 HUD 与动作验收

## 参考

- EA 官方《The Sims 4》主机版手册，第 16 页的 Live Mode 布局：https://eaassets-a.akamaihd.net/eahelp/manuals/the-sims-4-ps4-pt.pdf
- 实际渲染的参考页：`.runtime/references/sims4-live-hud-layout.png`。
- 人物、餐点及前次官方用餐视频记录：`character-and-dining.md`。

官方布局把游戏场景作为主体，时间控制收在底部中央，居民、当前活动和需求采用底部局部面板与标签切换。本项目按用户要求将居民信息进一步统一到右下角，不照搬品牌素材。

## 本轮结构

- 左上角为 44px 高的小型品牌、生活币和存档工具组。
- 右上角为生活、建造、角色的模式切换；不放在品牌容器内部。
- 右下角居民面板：44px 小头像、当前活动、取消按钮、需求/特质/邻居标签，支持折叠。
- 底部中央：时间与暂停、1/2/3 倍速合为一个组件。
- 地图改为入口按钮；建造属性按需打开，家具目录只在建造模式显示。
- 手机默认折叠居民面板，时间控制与居民面板分层排布，不相互覆盖。

文字使用项目既有字体，主要控制为 11-13px，动态数字使用等宽数字。浅色表面、叶绿色选中态与温和阴影沿用原有设计语言。场景本身是主视觉，不添加说明性大标题或功能介绍区。

## 动作验收

- 聊天：从点击开始预约并暂停目标邻居，双方朝向彼此，轮流 Talk/Listen；结束、取消、切换模式时释放邻居。
- 沙发休息：寻找可达接近点，进入坐垫位置，髋部按家具高度调整，结束回到无碰撞的站立点。
- 睡眠：对齐对应枕头，身体沿床长方向躺下，生成盖住身体的被子，眼睛闭合；起床后移除被子并恢复站姿。
- 电视：选择朝向电视的可用座位，播放程序化动画节目；暂停冻结画面，结束/取消关闭屏幕；观看镜头保证屏幕正面可见。
- 测试读取实际位置、姿态、邻居位移、画面像素与 UI 边界，不只检查进度数字。

这轮没有实现完整职业、关系成长、多人或所有家具的复杂交互，不能将上述状态机视为完整的《模拟人生》行为系统。
