# 晴屿 · Sunny Life

一个可运行的浏览器 3D 生活模拟原型。新访客直接创建居民，完成后进入生活；已有存档直接继续，没有前置落地页。

## 启动

```bash
cd sunny-life
npm ci
npm run dev
```

默认地址：<http://localhost:5186/>。也可以运行 `npm run start:background`，后台启动开发服务器；端口被占用时会自动选择后续空闲端口，进程信息记录在 `.runtime/server.json`。

## 已实现

- 低多边形海岸：干净的三角面草地、少量林边草簇、分层岩岸和重新建模的岩石；浅水透底、岸边泡沫及实时反射水面。
- 目的地导航：地图中可前往家园、望星塔、彩窗街、溪畔营地和月湾公园，角色使用桥梁与坡道通行。
- 房屋编辑：拖画墙体、拖建矩形房间、地板、门窗开口、原始外墙和自定义墙拆除；确认清空地块后可从空地建房。尺寸调整保护已有家具和扩建房间。
- 18 种家具：客厅、卧室、厨房、卫浴、花园分类，支持搜索、放置、配色、移动、旋转、复制、收回。
- 放置约束：地块边界、家具碰撞、墙体碰撞、缩小和扩建房屋时的家具保护。
- 历史记录：最近 40 次房屋编辑的撤销、重做，以及对应预算恢复。
- 角色编辑：低多边形成人比例、25 节点可动骨骼、衬衫/夹克/开衫三种穿搭，保留姓名、肤色、脸宽、眼睛、鼻部、身高、肩宽、四种发型、发色、服装配色、眼镜与性格特质。支持随机形象、应用与取消。
- 生活模式：A* 寻路、时间暂停与 1/2/3 倍速、饱腹/精力/社交/愉悦/清洁/如厕状态；可关闭的自主照料会选择可达设施，手动命令优先。
- 卫浴：实际坐到马桶、淋浴间进入/洗浴/退出、水流与手势、隐私遮挡；暂停和取消同步清理。旧存档可从房屋属性“添加卫浴间”。
- 持续需求恢复：活动进行中逐步增加对应需求，中途取消保留已获得部分，不重复发放完成奖励。清洁度衰减从每游戏分钟 0.105 降到 0.032。
- 任务队列：家具、聊天、散步、钓鱼最多排队 8 项，可提前、移除和清空。当前活动正常退出后执行下一项；暂停冻结，切换编辑模式清空；不可达任务跳过。
- 钓鱼：三个岸边钓点，走近、抛竿、浮漂等待、收线、收获；三种鱼获保存到个人记录。鱼获为休闲收集，不含出售、物理鱼群或实时收杆小游戏。
- 镜头：双向旋转、俯仰、正交/透视切换、按视角与活动位置自动剖墙。
- 轻量画质：镜头菜单可切换，降低像素密度、反射分辨率与更新频率，关闭实时阴影；4 线程及以下设备默认开启，也可通过 `?quality=low` 进入。功能与存档不变。
- 紧凑 HUD：右下角为可折叠居民面板，切换需求/特质/邻居并查看待办；底部中央合并时间与倍速。建造属性、钓鱼与鱼获按需展开。
- 家居与社交：聊天时邻居停止行走并面向玩家，双方轮流手势；沙发休息实际入座；睡眠对齐枕头、躺下并盖被；电视播放动态节目并调整观看视角。
- 用餐动作：选择松饼或沙拉，寻找可达餐椅，走近、入座、取食、抬手至嘴边、起身。IK 对齐餐具，食物逐渐减少；暂停同步冻结动作。
- 窗户对齐：墙体开洞、窗框、玻璃共用高度与地台基准，消除原来的 0.25 米错位。
- 存档：浏览器自动保存、手动保存、JSON 导出与导入、无效存档保护、场景截图下载。
- 响应式界面：桌面和手机，手机捏人模式保留完整角色视图。

## 操作

| 操作 | 方式 |
| --- | --- |
| 旋转镜头 | 普通模式在场景上拖动鼠标左键；手机单指拖动；左下双向旋转按钮 |
| 镜头设置 | 左下相机菜单内调整俯仰、正交/透视、自动剖墙与屋顶 |
| 平移镜头 | 鼠标右键拖动；手机双指拖动 |
| 缩放镜头 | 滚轮或左下角缩放按钮；手机双指缩放 |
| 放置家具 | 点击目录中的家具，再点击地面 |
| 编辑家具 | 点击场景内家具，使用右侧物品面板 |
| 旋转家具 | 选中或待放置时按 `R`，或点击旋转按钮 |
| 收回家具 | 选中后按 `Delete` / `Backspace`，或点击收回 |
| 建墙 | 选择墙体工具，按住拖动；也可依次点击起点和终点 |
| 建房间 | 选择方框工具，拖出矩形，生成地板、墙和入口 |
| 门窗 | 选择门/窗工具，点击墙体；同一墙段只保留一个自定义开口 |
| 拆墙 | 垃圾桶工具点击墙体，预设外墙也可拆；撤销可恢复 |
| 空地重建 | 房屋属性中选择清空建筑与家具，需要确认 |
| 自主照料 | 右下需求面板的开关；空闲且需求较低时自动寻找设施 |
| 取消操作 | `Esc` |
| 撤销 / 重做 | `Cmd/Ctrl + Z` / `Cmd/Ctrl + Shift + Z` |
| 手动保存 | `Cmd/Ctrl + S` |
| 居民行走 | 生活模式下点击地面 |
| 家具活动 | 生活模式下点击可互动家具，选择活动 |
| 排队 | 当前动作进行中继续选择其他活动，右下待办可调整顺序或移除 |
| 钓鱼 | 左上钓鱼入口选择岸边钓点，同一面板查看鱼获 |
| 用餐 | 点击餐桌、厨房或冰箱，选择餐点并开始用餐；需要可达餐桌 |
| 取消活动 | 点击居民活动旁的 X，或按 `Esc`；坐下或睡眠中会先起身，邻居会解除等待 |
| 暂停生活 | 生活模式下按空格，或点击暂停 |

存档使用当前浏览器、当前访问地址的 `localStorage`。每个访客有自己的居民和世界，不是共享世界或多人联机。更换端口、浏览器、设备或清理站点数据后不会共享存档，迁移前请导出 JSON。活动队列和未应用的捏人草稿不保存。首次创建未完成前不会覆盖已有存档；旧版存档无需重新捏人。

## GitHub Pages

`.github/workflows/pages.yml` 在 `main` 更新时安装依赖、执行规则测试与发布关键浏览器流程、构建并部署 `dist`。需要在仓库 Pages 设置中选择 GitHub Actions。

站点完全静态，模型随站点提供，不需要 API 密钥或游戏服务器。公开托管不提供账号、跨设备云存档和实时联机；大量访客分别在本机运行 WebGL，移动设备性能会影响帧率。

## 验证

```bash
npm test
npm run test:e2e
npm run build
```

浏览器测试使用 Playwright，首次使用且没有 Chromium 时运行 `npx playwright install chromium`。

## 技术与素材

- React 18 + Vite 6：游戏界面与本地开发。
- Three.js：正交/透视 3D 场景、模型、灯光、阴影、镜头和射线选择；使用官方 Reflector 处理实时平面反射，适配正交镜头裁剪。
- PathFinding.js：A* 网格寻路，禁止斜向穿角。
- robust-point-in-polygon：河岸、岛屿与高地的可靠区域判定。
- Lucide：界面图标。
- 沙发、休闲椅、茶几、床、落地灯和植物使用 Blender 制作的 GLB 模型，包含曲面、缝线、褶皱与 PBR 材质。模型资源随项目本地提供，加载失败时回退至基础模型。
- 松树、阔叶树、岩石、倒木、彩色楼房、尖顶塔、木桥、水井、帐篷、小船使用新增的 10 种 Blender 场景模型。
- 人物头部、眼睛、眉毛和发型采用 Quaternius Universal Base Characters 的 CC0 资源，经 Blender 裁切、重新绑定和配色归一化后，接入本项目身体、服装和骨骼。使用 Three.js AnimationMixer 播放动作，CCDIKSolver 对齐餐具。授权与改动见 `art/vendor/quaternius/README.md`。
- 可编辑的自家房屋、部分家具、草地着色器与实例化草叶、餐点、卫浴、动态被子和电视节目由本项目生成；目录缩略图由实际模型实时渲染。
- 字体使用可选的 Google Fonts DM Sans；无法联网时回退到系统字体，不影响游戏。

核心文件：`src/game.js`（规则/存档/寻路）、`src/models.js`（模型）、`src/model-assets.js`（GLB 加载与染色）、`src/world.js`（渲染/交互）、`src/action-queue.js`（待办）、`src/fishing.js`（钓鱼）、`src/ocean.js`（海面）、`src/App.jsx`（状态与界面）。

`src/world-layout.json` 是地形、桥梁、建筑、树木和目的地的共享布局。`src/terrain.js` 负责高度、可达性和旧存档位置恢复，`src/environment.js` 负责岛屿、动态水面及场景组装。水域不可步行，陡崖必须绕行，旧存档落在新水域时只恢复角色位置，不重置房屋或居民。

## Blender 建模

源文件：[`art/blender/sunny-furniture.blend`](art/blender/sunny-furniture.blend)。可以用 Blender 继续修改；运行网页不需要 Blender。

```bash
npm run models:export
```

该命令从现有 `.blend` 导出，不覆盖手工修改。`npm run models:rebuild` 会从脚本重建整套源文件。详细说明见 [Blender 工作流](art/blender/README.md)。

新增场景素材源文件：[`art/blender/sunny-world.blend`](art/blender/sunny-world.blend)。

```bash
npm run world:export
```

`world:export` 保留手工修改；`world:rebuild` 重新生成素材源文件。关卡布局由 `world-layout.json` 控制，素材源文件不是关卡布局文件。

人物源文件：[`art/blender/sunny-resident.blend`](art/blender/sunny-resident.blend)。

```bash
npm run resident:export
```

`resident:export` 从现有文件导出模型与八段动作，不覆盖手工修改；`resident:rebuild` 从脚本及 `art/vendor/quaternius` 中的 CC0 来源重新构建。研究来源、视频截帧位置与授权边界见 [人物和用餐参考](art/references/character-and-dining.md)，新 HUD 和动作约定见 [生活模式参考](art/references/live-mode-hud.md)。

本轮场景拆解、建造数据、颈肩连接、自主生活与真实世界映射方案见 [场景、建造与自主生活](art/references/scene-building-and-needs.md)。尚未实现 GIS 导入，不将青禾镇称为真实地点。

## 原型边界

这是单机、单层矩形房间、有限河谷群岛的原型，不是完整的《模拟人生》替代品。尚无任意闭环墙自动生地板、斜墙、多层楼梯或门扇动画。邻居住宅和望星塔暂不可进入，尚无职业、家庭关系、多人联机、云存档、任务系统或无限世界生成。角色为风格化人物，捏人不是写实网格雕刻。用餐、聊天、休息、睡眠、电视、洗澡和如厕具有对应行为；阅读、园艺仍以寻路与进度反馈为主。自主系统目前管理玩家居民的基本需求，性格特质暂不参与复杂行为评分。
